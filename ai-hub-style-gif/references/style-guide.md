## 粉紅藍色家族的設計起點（近似值，非官方品牌規範）

| 元素 | 建議起點 |
|---|---|
| 畫布 | 1080 × 1350，4:5 |
| 背景 | #F1F1EF 至 #E8E8E8，極淡紙感可選 |
| 標題靛藍 | #28205F |
| 標題灰粉紅 | #D75D83 |
| 分類粉紅 | #F27FAC |
| 分類藍 | #5999CF |
| 內文 | #111111；深色分類底可用白字並檢查對比 |
| 字體 | 英文粗體無襯線、略窄標題；中文選可用的繁體黑體粗體，避免硬壓窄中文字 |
| 外緣安全區 | 約 40–56 px，裝飾可出血，文字不出血 |
| 標題 | 約 64–88 px；長標題分兩行而非無限縮小 |
| 分類名稱 | 約 28–34 px，可分兩行 |
| 項目標籤 | 約 26–30 px 起，必要時分頁 |
| 圖示徽章 | 約 62–82 px，白底圓形，陰影很淡或省略 |
| 分類色塊 | 圓形或小圓角矩形，避免巨大圓角卡片 |
| 連線 | 約 2–4 px；先畫線，再畫徽章覆蓋交接處 |
| 資料流小點 | 約 6–10 px，粉紅或藍，沿線移動 |

原圖部分標籤低於上述建議，屬高密度取捨，不是必須重現的缺點。一般先以 5–8 類、每類 3–6 項試排；這是起點，不是數量規定。需完整大型地圖時，可保留高密度總覽，再提供可讀細節頁。

## 主題轉譯

工具生態系 → 依功能分群，而非排名。
HR 架構 → 人事、招募、薪酬、訓練、績效等實際模組，用一致線條圖示取代工具商標。
工作流程 → 用真實階段排序；平行選項放同列，依賴另行標明。
知識地圖 → 中心是問題或主題，分類是可解釋的面向；不要為填版面虛構內容。

## 可套用的視覺 brief

「以 {主題} 製作 1080×1350 的 LinkedIn 生態系資訊圖。採 {放射分類／分層路線}，灰白底，靛藍與灰粉紅粗體標題，粉紅與藍色交替分類，圓形圖示徽章與細連線。資料為 {分類與項目}，閱讀路徑為 {關係說明}。文字用 {語言}，品牌用 {已提供的資產／省略}。保留手機可讀性，文字以可編輯排版呈現。{若需動態：版面固定，小圓點沿線移動，5–6 秒無縫循環，另附靜態圖。}」

若需生成裝飾插畫，另寫素材提示詞：白色與銀灰色的小型友善機器人、少量藍色光點、自然持筆電、乾淨輪廓、適合右下角局部出血；透明背景，不要文字、標誌或整張資訊圖。此為可選延伸，不是對第二張原圖機器人的複製要求。

## 其他視覺家族

- 白底彩色分類：每類一色，左側編號＋圖示膠囊，右側白色圓角工具列、細灰框與輕陰影。色相變化用來分組，不代表排名。
- 技術流程：白底、淺色分區、深灰細箭頭；藍／青綠／紫或綠／赭／紫分別對應概念。圖示、箭頭、短說明承擔主要解釋，減少散文。
- 米色紙感：背景可從 #F2EBD9 起，森林綠 #376442、赭色 #A66A24 作起點；僅用淡紙紋，保持文字對比。適合知識地圖、職涯與專案樹。
- 指令視窗：背景奶油白 #F8F5EF、深灰 #302C28、珊瑚橘 #D77959；細圓角邊框、上方小圓點、襯線標題搭配清楚內文。命令與說明雙欄對齊；命令內容只是示意，不能宣稱參考中的斜線命令都是產品內建功能。

以上色碼是實作起點，不是從原圖精密取樣的品牌值。混合家族時維持同一套圖示、字級與連線規則。
