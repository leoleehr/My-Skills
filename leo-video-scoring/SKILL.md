# Leo 影片配樂流程

為 Leo 的影片寫一段**原創**配樂，用真實樂器取樣渲染，和弦切點對齊畫面分鏡，量測平衡後合成進影片。
本流程整合了 jtydhr88/music-composition-skills（MIT）的編曲結構、聲部層次準則，以及實際製作中累積的取樣與混音做法。

## 0. 鐵則

1. **先交 wav 試聽，確認後才編進影片。** Leo 的習慣是逐輪聽、逐輪改。
2. **不引用受版權保護的旋律與和弦進行**（例如 Coldplay〈Fix You〉）。只參考情緒走向與手法；1929 年前的作品（巴哈、蕭邦）屬公眾領域，可直接引用，但要先說明和弦將無法對齊分鏡。
3. **不要合成音色。** Leo 明確否決過合成鋼琴與合成墊音；一律使用真實取樣。
4. **主旋律永遠在最前面。** Leo 曾因「右手旋律被左手打擾」退件；每一版都要量測各聲部音量（見 §5），不憑感覺。
5. **誠實交代限制**：無法親耳聆聽，只能回報量測數據；取樣若是聲部（section）而非獨奏，要說清楚。

## 1. 動筆前必填（缺一不可）

| 必填 | 問法 |
|---|---|
| 分鏡時間軸 | 每一幕的起訖秒數；和弦一律換在切點上 |
| 能量目標 | 全曲最高點在哪一幕？最低點在哪一幕？（能量曲線**必須有下降**，不可單調遞增） |
| 減法事件 | 哪一處撤掉樂器？撤什麼？為何在那裡撤？（通常是情緒最重的那一句） |
| 進退場表 | 每件樂器何時進、何時退；**至少一件中途進場、至少一件提前退場**，開場不鋪滿 |
| 記憶點 | 不靠旋律主體，聽眾能記住什麼（一個動機、一個音響事件，例如片尾配合 Logo 拼合的疊音） |
| 結尾方式 | 鏡像（依進場反序退場）、循環加減、或淡出；說得出選哪一種 |

## 2. 結構：起承轉合對應能量曲線

- 起：最少編制，主題呈示（例：大提琴＋鋼琴）。
- 承：樂器依序加入，主旋律在樂器間**接力**（大提琴→中提琴→第二小提琴→第一小提琴），每次交棒後前一件退回伴奏。
- 轉：全員到齊後，在最重的那句話做**減法**：只留主旋律＋鋼琴分解和弦。
- 合：全員重新進場為最高點；結尾樂器依進場反序退出，最後的和弦與片尾 Logo 動畫同步。
- 能量自檢：把每段能量寫成 0–10 數列，不得非遞減。

## 3. 聲部層次規則（texture）

- 聽眾把「高、響、快、變化率快」的聲音當前景；**背景的變化率不可高於前景**。高點時只允許一個伴奏聲部快速流動（例如大提琴分解和弦），其他伴奏放慢或拿掉。
- 兩層打架時依序試：音色 → 音區 → 演奏法 → 件數 → 八度幅度 → 力度（力度最後）。
- 伴奏音域放在主旋律下方，但避免緊貼；次要聲部在主旋律頻段內輕不到約 20 dB 就等於聽不見，寧可移音區。
- 踏板／長音不要讓舊音堆積：延音上限約 1.6–1.8 秒，換和弦即放。

## 5. 渲染與混音流程

1. **取樣器**：讀檔→去開頭靜音→就近取樣移調（np.interp 重取樣）→指定長度後以指數釋音（弦樂 0.12–0.25 秒、鋼琴制音約 0.14 秒）→依聲部聲像放置（四重奏：一小提 -0.4、二小提 -0.15、中提 +0.18、大提 +0.4）。
2. **每個聲部寫進獨立 stem**，最後才依 LEVEL 混合，方便量測與調整。
3. **逐段量測**：每段計算各 stem 的 RMS（dB）。目標：主旋律比伴奏高 3–7 dB；減法段整體低約 5–7 dB；最高點最響。不合格就改寫法或調整 stem 等級，再量一次。
4. **空間**：以指數衰減雜訊 IR 卷積做殘響（鋼琴／四重奏約 2.4–2.8 秒，濕度 0.20–0.26），高通 30–45 Hz，片尾 1.6–2 秒淡出。
5. **標準化**：`ffmpeg -af loudnorm=I=-16:TP=-1.5:LRA=11`，48 kHz。
6. **合成進影片**：`ffmpeg -i video.mp4 -i score.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k -shortest -movflags +faststart out.mp4`，再量一次整體響度。

## 6. 已驗證的寫法庫

- **蕭邦夜曲風**：降 E 大調；左手**十度伴奏**（低音＋高十度輕微分解，再接內聲部，每 0.5 秒一音）；右手旋律**大跳後級進回落**，音符相互連奏；裝飾音最多兩處；左手整組比旋律低約 9 dB 且濾暗。
- **巴哈無伴奏風**：前奏曲式分解和弦（低音、跨弦往上、頂端鄰音勾旋律），中段改薩拉邦德慢速雙音。
- **弦樂四重奏＋鋼琴**：承段伴奏用八分音符律動（中提＋二小提）、大提每秒換弓；高點大提琴分解和弦、二小提在主旋律下三度齊奏、鋼琴只留左手。
- 情緒參照的轉換：「像 Fix You」→ 安靜私密起、穩定推進、充滿希望的高點（只借弧線，不借音符）。

## 7. 交付格式

每次交付在回覆中說明：
- 段落表（秒數｜段落｜編制與手法）。
- 實測數據（各段整體 dB、主旋律與伴奏差距）。
- 授權與需加註的出處文字。
- 邀請 Leo 指出「第幾秒附近、哪裡不對」，下一輪只改那一段。

## 8. 交付前檢查

- [ ] 和弦切點對齊分鏡
- [ ] 能量數列不是非遞減，且有一處明確減法
- [ ] 進退場表：至少一件中途進場、一件提前退場
- [ ] 背景變化率不高於前景；主旋律在各段量測中最大聲
- [ ] 響度 -16 LUFS、峰值 ≤ -1.5 dBTP
- [ ] 無受版權保護的旋律；出處文字已附上
- [ ] 先交 wav，確認後才合成影片
