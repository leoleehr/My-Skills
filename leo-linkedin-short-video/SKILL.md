# 60秒談人資：LinkedIn 短影音製作流程

將 Leo 的一篇 LinkedIn 文章轉成一支**剛好 60 秒**的品牌短影音：Leo 本人肖像站在會議室簡報螢幕旁，螢幕逐幕播放重點動畫，下方字幕逐字出現，配上與分鏡對拍的原創鋼琴＋弦樂配樂，片尾 LR 標誌拼合後淡出。

配樂細節另見 `leo-video-scoring` skill；寫作語氣一律套用 `leo-voice` skill。

## 0. 鐵則（Leo 明確要求過的）

1. **總長剛好 60 秒**：0–56 秒內容，56–60 秒品牌片尾，59.2–60 秒畫面與音樂同步淡出。系列名稱「60秒談人資」。
2. **影片每一句都要能在原文找到出處**。不得自行推論或加強語氣（曾被抓出：備忘錄「提到」被寫成「承諾」、漏掉「約」六萬、自創「難以重建」）。交付前逐句對照原文。
3. **簡報斷點＝音樂換和弦點**，用程式核對，不憑估計。
4. **字幕與文字必須在淡出前讀得完**；片尾文字最晚 57.4 秒出齊。
5. **網站尚未公開時，影片不放網址、不做網站宣傳**（標語、網址需先問 Leo）。
6. 依 Leo 的要求決定順序：說「先給腳本過目」就先交腳本，確認後才產出；配樂改動先交 wav 試聽，確認後才合成。

## 1. 腳本：從文章到 11 幕

標準分鏡（斷點全落在整秒，配樂每拍 1 秒）：

| 幕 | 秒數 | 用途 |
|---|---|---|
| 1 | 0–5 | 標題問句（hook），開場第 0 幀即完整標題，兼作封面 |
| 2 | 5–12 | 事實查證（數字＋限定條件卡） |
| 3 | 12–18 | 拆解（例：拆開一個職位） |
| 4 | 18–23 | 代價或對照（例：天平） |
| 5 | 23–28 | 檢核清單（四個問題） |
| 6 | 28–33 | 行動階梯 |
| 7 | 33–39 | 兩欄對照 |
| 8 | 39–48 | 情緒最重的一句，大字引言、其餘留白（配樂同步做減法） |
| 9 | 48–52 | 回到自己 |
| 10 | 52–56 | 收束（雙圓交會） |
| 11 | 56–60 | 品牌片尾：LR 標誌拼合＋收尾金句 |

寫作規則：
- 字幕語速約每秒 4.8 字；每幕字數 ≤（幕長 − 0.9 秒）× 4.8，超過就縮句，不要壓縮閱讀時間。
- 片尾金句 0.6 秒內整句出現（不逐字打），確保淡出前可讀。
- 套用 leo-voice：無「不是…而是／而非」、無破折號、「把」改「將」、人一律稱「夥伴」；開頭立「我」或用「試想」，收尾轉「我們／個人」。
- 數字照原文限定詞（「約」「符合資格」「不等於實際離職」）；引用他人文件用「提到」，不升級成「承諾」。
- 交付時附：分段腳本表、連續朗讀版、與原文逐句核對表（含「影片未收錄的原文重點」）。

## 2. 畫面：會議室簡報人像

- **主視覺**：沿用 leoleehr.com 深色主題。底色漸層 #283568 → #16161a；文字 #ececed、次要 #a8a6ad；藍 #7B92E8（AI）、淡紫 #acb8ff、沙金 #c9b78f（夥伴／判斷）、粉 #cfa2bd（人力調整）。字型：中文 Noto Sans CJK TC、英文 Wix Madefor Display、標籤 JetBrains Mono（從網站 `/fonts/*.woff2` 取得，用 fontTools＋brotli 轉 ttf、instancer 固定字重）。
- **標誌**：`leoleehr.com/media/logo-mark-dark.svg`（L、兩道斜筆、R 四個 path），用 cairosvg 拆成四個部件，片尾依序拼合（L 上升、斜筆對角滑入、R 最後）。
- **人像**：Leo 提供的實拍照，用 `rembg`（`isnet-general-use`，alpha matting fg 240 / bg 15 / erode 8）去背，**五官不做任何生成或修改**。目前定版用手持人資書的半身照，縮放 0.46、頭頂約 y=140，桌緣（y=872）遮住手部、露出書名。加輕微呼吸（±0.6%）與擺動（±3 px）。
- **場景**：1920×1080；左側壁掛螢幕 1060×596 於 (50,128)，螢幕內投影片以 2 倍解析度繪製；右側石板灰牆板與主光；前景木質會議桌帶反光；鏡頭全程推近 4%。
- **畫面元素**：左上 LR 小標誌＋「LEO LEE HR」、右上頁碼「01 / 11」、底部進度條；開場 4 秒名牌「李奕勳 Leo Lee｜Strategic HR × AI Transformation」。
- **字幕**：底部圓角半透明底，逐字出現；超過 1500 px 寬時在「；」處斷成兩行。
- **投影片動畫**：每幕英文小標籤＋大標，元素以 ease-out 上浮淡入，幕與幕之間 0.35 秒交叉淡化。

## 3. 配樂（細節依 leo-video-scoring）

目前定版：**鋼琴獨奏（Salamander Grand Piano）＋小聲弦樂團墊底（VSCO 2 CE）**，E 大調、每拍 1 秒（60 bpm）。

- **對拍**：所有音（左右手、弦樂）100% 落在整秒拍點上；和弦只在整秒換，簡報斷點取其子集。
- **和聲**：大量 maj7（Amaj7、Emaj7、Emaj7/G#、Emaj7/D#、Dmaj7 等），小和弦用 m7；轉段前保留 F#m7 → A#dim7 → B7；結尾一定是 **ii6/5 → V7（旋律唱導音）→ Imaj7**，旋律落在主音。
- **大七音避讓**：伴奏中的大七音不得落在旋律音下方半音或下方一個八度又半音（小九度）；放到次中音區或移低八度。
- **觸鍵**：力度層 v6/v10 依力度交叉淡化、句子中段漸強句尾放輕、伴奏延音到換和弦、旋律相鄰音微重疊。
- **編排**：0–12 秒鋼琴獨奏；12 秒大提琴＋中提琴墊底；23 秒加低音提琴與小提琴；33 秒三聲部到齊；39–48 秒聖詠做減法；48 秒高點只比前段略滿（Leo 不要史詩感：不用定音鼓、高點不用法國號）；56 秒 Emaj7 撐到 59.2 秒，最後 0.8 秒淡出。
- **平衡**：旋律比伴奏高 3–9 dB；弦樂比旋律低 8–11 dB、高頻濾到 3.2 kHz；整體 -16 LUFS（loudnorm 後再以 volume 微調至 -16.0），峰值 ≤ -1.5 dBTP。

## 4. 合成與淡出

```bash
ffmpeg -i silent.mp4 -i score.wav -map 0:v -map 1:a \
  -vf "fade=t=out:st=59.2:d=0.8" -af "afade=t=out:st=59.2:d=0.8" \
  -c:v libx264 -preset veryfast -crf 17 -pix_fmt yuv420p \
  -c:a aac -b:a 192k -shortest -movflags +faststart out.mp4
```

## 5. 交付前驗證（全部用程式量，不靠感覺）

- [ ] 時長：影像與音訊都是 60.000 秒
- [ ] 斷點對齊：列出簡報斷點與音樂換和弦點，確認前者全包含於後者
- [ ] 對拍率：攔截所有音符起點，統計落在整秒的比例（目標 ≥ 98%，現行 100%）
- [ ] 終止式：最後 4 秒做 chroma 分析，確認 56 秒後主音 E 最強
- [ ] 抽幀：第 0、57.6、59.0、59.9 秒截圖，確認封面完整、片尾文字出齊、淡出漸黑
- [ ] 響度：-16 LUFS、峰值 ≤ -1.5 dBTP
- [ ] 文字：影片每句對照原文；跑 leo-voice 自檢

## 7. 已知陷阱

- 工作環境只能連 GitHub 與套件庫；網站檔案可用 curl 直接抓，WebFetch 常被擋。
- VSCO 2 的弦樂、木管、銅管檔名比實際音高低一個八度（+12）；Salamander 檔名即實際音高。
- 片尾動畫若放慢、或字幕逐字打出，會被淡出截斷；寧可加快片尾，也不要把總長拉超過 60 秒。
- 換和弦若同時出現在整秒與半秒，聽感重拍會跳動，被聽成「反拍」；全曲固定在一個拍點網格上。
